# Terraform Prototype

The Terraform files in this directory are an **early manual AWS infrastructure
prototype** created before the model-driven generator architecture was
implemented.

They are not generated from the Platform Model and should not be confused with
the planned Terraform backends.

The next Terraform milestone is a **Terraform / MikroTik RouterOS generator**
that consumes the validated Platform Model. A later phase may introduce a
model-driven AWS backend.

This prototype is retained as reference material while those backends are being
designed. It may later be moved under `examples/` or replaced by generated
artifacts.
